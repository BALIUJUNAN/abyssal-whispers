## 第一部分：沃切斯特调查报告

### 你是谁

1926年深秋。你来到马萨诸塞州东南海岸的港口城市沃切斯特。原因不重要——失踪案委托、学术邀请、或者只是在错误的时间出现在了错误的地点。

重要的是：一旦踏入这座城，你就再也无法轻易离开。

### 发生了什么

教堂的钟声每天敲响十三下。码头的潮汐与任何时刻表都不吻合。公告栏上贴着你的失踪告示——上面的照片是你，但你还没拍过那张照。

三百年前莫里斯家族在此建立了封印。三百年后，封印开始松动。深潜者从海岸裂隙中爬出，夜魔在森林中低语，地下墓穴里传来有节奏的敲击声——仿佛某个庞然之物正在苏醒。

### 怎么玩

打开 `index.html`。推荐 Chrome 或 Edge。无需安装，无需联网（首次加载后完全离线可玩）。

**在线体验**: [baliujunan.github.io/abyssal-whispers](https://baliujunan.github.io/abyssal-whispers/)

### 核心循环

```
每日 12 行动点 → 探索 / 对话 / 调查 / 休息
                ↓
           触发事件（技能检定 d100）
                ↓
        HP 归零 = 死亡 → 轮回
        SAN 归零 = 疯狂 → 轮回
                ↓
        保留知识碎片与部分记忆
        世界污染度永久叠加
        再次踏入沃切斯特
```

- **28 天封印倒计时** — Day 1 钟声异常，Day 7 核心NPC开始腐化，Day 14 深潜者大潮，Day 21 疯狂之夜，Day 28 封印破碎
- **每次轮回都更难** — SAN 上限削减 3 点，NPC 逐步识别你是重复访客
- **死亡不是终点** — 每次死亡都会在下一周目以"回声事件"形式兑现

每位 NPC 有 6 级信任体系、独立腐化触发器、专属救赎路径。沉默同样影响人性判定——不回答本身就是一种回答。

### 理智系统

SAN 不是血条。它是你与现实之间的契约强度。数值下降时，游戏本身开始对你撒谎：

| SAN 区间 | 临床记录 | 表现 |
|----------|---------|------|
| 80-100 | 认知稳定 | 世界按既定规则运转 |
| 60-79 | 轻度侵蚀 | 文字偶尔错位，幻听，NPC说出超越当前信息量的话 |
| 40-59 | 感知偏移 | 区域名称变更，选项文本被认知改写，日志出现陌生笔迹 |
| 20-39 | 解释权丧失 | 看到不存在的选项，存档文件名自行改变 |
| 1-19 | 现实崩解 | UI 层呈现某种意志，事件文本否认你的既有记忆 |

第四面墙事件在 SAN 极低时激活：伪造存档通知、注入虚假错误代码、篡改物品描述。UI 本身成为恐怖载体。

## 第二部分：技术档案

> 以下内容面向开发者与对交互叙事工程感兴趣的研究者。

### 架构总览

```
React (CDN) + useReducer 全状态驱动
         ↓
    Lazy-clone Reducer 模式（嵌套对象按需浅拷贝）
         ↓
    {GD} Context 单例（游戏数据全局访问，无全局变量）
         ↓
    JSON 配置驱动（事件/结局/效果/NPC 全部数据化）
```

单文件构建产物 `index.html`，包含完整运行时：React 18 + 18 个 Reducer 模块 + ~700 个事件定义 + 完整样式表。

### 状态管理分层

| 层级 | 文件 | 职责 | 行数 |
|------|------|------|------|
| 主逻辑 | `app.jsx` | React 组件树 + 入口 | ~1491 |
| 事件调度 | `reducers/extendedEvents.js` | V2 选择器，30+ 触发条件，预算控制，冷却追踪 | 534 |
| 死亡系统 | `reducers/deathSystem.js` | 五层优先级推理链，四段式叙事生成 | 381 |
| 样式动画 | `styles.css` | 四字体架构 + UI腐败三层递进 + 14 组关键帧 | ~278 |
| 游戏数据 | `game_data.json` | 世界规则 / NPC / 道具 / 区域 / 结局 | ~550 KB |

### V2 事件调度器

核心函数 `selectEventV2` 的决策链：

```
1. 章节约束检查（当前章节允许的事件类别）
   ↓
2. 区域过滤（当前所在区域的事件池）
   ↓
3. 触发条件评估（30+ 种条件：SAN阈值 / 轮回次数 / NPC状态 / 道具持有 / 人性值 ...）
   ↓
4. 日预算控制（每类事件每日上限，防止同类事件刷屏）
   ↓
5. 独立冷却追踪（每个具体事件的最低间隔）
   ↓
6. 加权随机抽取（权重 = 基础权重 × 当前条件系数）
```

### 死亡推理链

五层优先级，从最精确到最宽泛：

```
事件直接指定 death_hint（最高）
        ↓
事件标签匹配（如 water → drowning）
        ↓
SAN/HP 模式分类（san_zero → 精神死亡池 / hp_zero → 肉体死亡池）
        ↓
区域启发式（harbor →溺水高概率 / catacombs→坠落高概率）
        ↓
默认值兜底（最低）
```

物理死亡（溺死/失血/感染/饥饿/坠落/黑暗吞噬）与精神死亡（疯狂/附身/身份抹除/神话吞噬/循环崩塌/成为事件）使用完全不同的叙事风格库。

### 数据驱动设计原则

所有叙事内容由 JSON/JS 数据文件定义，非硬编码：

```
game_data.json          → 世界规则 / NPC 定义 / 道具表 / 区域配置 / 结局矩阵
events_*.js (12 files)  → 632 个扩展事件，按领域分模块
events_meta.js          → 36 个元叙事事件（第四面墙层）
events_death_echo.js    → 17 个死亡回声（轮回闭环）
ending_missing_600.js   → Meta 隐藏结局（动态注入）
```

新增事件或修改叙事文本不需要改动任何 reducer 代码——只需在对应数据文件中添加条目。

### 构建流程

```bash
python build.py              # 标准构建（Babel CLI 编译 JSX）
python build.py --no-babel   # 降级构建（Babel standalone CDN）
```

`build.py` 执行步骤：
1. 读取 HTML 模板 (`index.template.html`)
2. 内联 CSS 样式表
3. 拼合 18 个 reducer 模块（剥离 ES module 语法）
4. 读取并内联主逻辑 `app.jsx`（剥离 import）
5. 压缩合并 `game_data.json` 与 12 个外部事件文件
6. Babel JSX 编译（可选）
7. 输出自包含的单文件 `index.html`

### 字体与视觉架构

| 用途 | 字体 | 场景 |
|------|------|------|
| 叙事文本 | Noto Serif SC | 事件描述、对话、死亡叙事 |
| 界面文字 | Noto Sans SC | 按钮、面板标题、状态栏 |
| 系统消息 | JetBrains Mono | 日志、错误提示、元叙事层 |
| 私人笔记 | LXGW WenKai | 线索笔记、档案条目 |

UI 腐败三层递进（CSS class: `.corruption-1/2/3`）：
- Level 1: 文字阴影偏移 + 边缘泛光
- Level 2: 高频闪烁 + 色相漂移
- Level 3: 模糊衰减 + 不规则抖动 + 扭曲滤镜

SAN 视觉反馈两级：`.tremor`（微颤）/ `.fracture`（不规则抖动）。转场动画共 14 组关键帧序列，覆盖移动/休息/日期推进/SAN骤降/物理死亡黑屏/精神死亡扭曲等场景。

### 性能策略

- React.memo 组件级缓存（四主面板）
- useMemo 计算级缓存（区域连通性、在场NPC列表、结论进度、死亡回放构建等）
- 事件数据懒加载（按模块按需注入）
