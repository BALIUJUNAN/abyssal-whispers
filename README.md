## 档案概要

1926年深秋，马萨诸塞州东南海岸。沃切斯特——一座被浓雾常年笼罩的港口城市。三百年前莫里斯家族在此建立了封印。三百年后，封印开始松动。

你来这里是为了调查一起失踪案。但教堂的钟声每天敲响十三下，码头的潮汐与任何时刻表都不吻合，而公告栏上已经贴上了你自己的失踪告示。

死亡不是终点。每一次轮回，世界都变得更不对劲。

**双击 `index.html` 即可运行。推荐 Chrome 或 Edge。**

## 人物档案

### 老费舍 — FILE 01
渔夫。港口最老的居民，血管里流着不属于人类的东西。他见过封印完整时的样子，也记得那之后每一个失踪者的名字。

### 玛莎·格雷 — FILE 02
酒吧老板娘。安全屋的实质掌控者，镇上唯一不问来处的女人。信任她到第三级时，她会告诉你码头那些货物的真正来源。

### 希尔达·莫里斯 — FILE 03
沃切斯特庄园现任主人。封印家族最后一位直系后裔。她的血脉是维持封印的最后锁扣——也是打破它的唯一钥匙。

### 伊莎贝拉·韦伯 — FILE 04
教堂执事。掌管着这座城市被禁止的知识。她的救赎路径与常人不同——因为她从一开始就知道自己无法被救赎。

### 伊莱亚斯·沃德 — FILE 05
学者。神话知识的系统性来源。能解读那些不应该被解读的文字，代价是他自己的理智正在以可测量的速度流失。

### 约书亚·布莱克 — FILE 06
退伍军人。战争带走了他的平静，沃切斯特正在带走他的其余部分。他的沉默不是冷漠——是在努力分辨哪些记忆属于战场、哪些属于这座城。

### 汤米·陈 — FILE 07
报童。十二岁，城市消息网络的实际节点。他能进入成年人无法到达的地方，看到成年人选择性忽视的东西。

### 拉维尼亚·沃德 — FILE 08
画家。伊莱亚斯的女儿。感知阈值异常——她画出的东西往往在三天后才出现在现实中。

## 系统架构

### 认知污染系统（SAN）

SAN值不是血条。它是你与现实之间的契约强度。当数值下降，游戏本身开始对你撒谎：

| 阈值 | 临床记录 | 表现 |
|------|---------|------|
| 80-100 | 认知稳定 | 世界按既定规则运转 |
| 60-79 | 轻度侵蚀 | 文字偶尔错位，幻听，NPC说出超越当前信息量的话 |
| 40-59 | 感知偏移 | 地图区域名称变更，选项文本被认知改写，日志出现陌生笔迹 |
| 20-39 | 解释权丧失 | 看到不存在的选项，存档文件名自行改变，NPC用错误的名字称呼你 |
| 1-19 | 现实崩解 | UI层开始呈现某种意志，事件文本否认你的既有记忆 |

感知腐败系统综合五个维度——SAN值、轮回次数、神话知识积累、安全屋污染等级、当前所在区域——产生文字扭曲、焦点漂移、边缘泛光等递进式视觉异常。

第四面墙事件在SAN极低时激活：伪造存档通知、注入虚假错误代码、篡改物品描述文本。UI本身成为恐怖载体。

### 元叙事事件序列

从第五次轮回起解锁。按恐惧螺旋递进排列，不可逆：

| 轮回层级 | 事件类别 | 数量 | SAN阈值 | 特征 |
|----------|---------|------|---------|------|
| Loop 5+ | 感官污染 | 10 | ≤30 | 笔记本上未写的字开始蠕动；枯枝断裂后的两秒静默中，声音倒着播放回来 |
| Loop 6+ | 系统伪造 | 8 | ≤20 | 存档通知弹出后，时间显示从Day 6变为Day 7；"连接已断开"消息消失后，街上少了一个NPC |
| Loop 7+ | 选择消除 | 6 | ≤15 | 未选择的那条路被从可能性空间中删除；"未来"这个概念开始溶解 |
| Loop 8+ | 身份揭露 | 5 | ≤15, 神话≥5 | 手背浮现 `character_sheet.player_01`；NPC试图说出你的循环次数时被某种力量静音 |
| Loop 9+ | 存档干预 | 4 | ≤10 | 退出按钮上的"否"消失前，"是"上面有一个不是你的指纹 |
| Loop 10+ | 作者低语 | 3 | ≤5, 概率0.5% | 一行文字出现在屏幕底部，停留三秒后消失。内容因观测者而异 |

### 轮回机制

继承规则：30%技能碎片保留，暗道位置已知，NPC弱点已记录，人性值跨周目传递。
代价规则：每次轮回削减SAN上限3点，世界污染度永久叠加，NPC逐步识别出重复访客。

NPC对轮回者的反应分三层阈值：

| 轮回次数 | 世界层面的回应 |
|---------|---------------|
| 第1次 | 你第一次踏入沃切斯特 |
| 第2-4次 | 你似乎来过这里 |
| 第5-7次 | 核心NPC出现明确的既视感反应 |
| 第8次以上 | NPC直接表述"你又来了"；地图上不属于这里的路径开始消失 |
| 第10次以上 | 第600号事件自行显现 |

死亡回声闭环：死亡文本中的残留描述（"水面上会漂着一件外套，口袋里有你不该看的东西"）将在下一周目以回声事件形式兑现。

### 死亡系统

15种精确死亡类型，每种对应四段独立叙事结构：

1. **判词** — "你死于溺水。"（或附身/疯狂/身份抹除/循环崩塌/成为事件）
2. **终末** — 第一人称感官沉浸，每种死亡有独特的身体性描写
3. **处理** — 世界对你死亡的冷淡行政程序，视角抽离
4. **残响** — 对下一周目的污染预告，构成回声闭环的前半环

类型推理采用五层优先级链：事件直接指定 `death_hint` > 事件标签匹配 > SAN/HP模式分类 > 区域启发式 > 默认值。物理死亡（溺水/失血/感染/饥饿/坠落/黑暗吞噬）与精神死亡（疯狂/附身/身份抹除/神话吞噬/循环崩塌/成为事件）使用完全不同的叙事风格库。

死亡叙事使用专用衬线字体渲染（Noto Serif SC），`line-height: 1.9`，与系统消息的等宽灰斜体形成类型学区分。

### NPC生态

每位核心NPC配备6级信任体系（每级含完整对话分支）、独立腐化触发器、专属救赎路径及轮回记忆变体。

对话行为矩阵包含六种交互向量：建立信任 / 询问情报 / 分享食物 / 尝试救赎 / 沉默 / 告别。其中"沉默"同样影响人性判定——不回答本身就是一种回答。

### 结局矩阵

结局由三维坐标定位：

1. **世界轴** — 封印重铸 / 港口逃离 / 深渊胜利 / 存在超越 / 循环破壁
2. **代价轴** — 承担者归属（玩家 / 指定NPC / 共同承担 / 无人）
3. **人性轴** — 尚存人性 / 人性脆弱 / 人性迷失

四层结局叙事生态：预兆（条件接近时出现的暗示性事件）→ 达成（满足条件的正式结局）→ 余波（上一周目结局在本周目的回响）→ 交织（多结局解锁后的元叙事层）

### 封印生命周期

城市拥有独立的28天恶化周期：

```
Day  1   封印完整 —— 钟声首次异常，第一张失踪告示
Day  7   封印松动 —— 第一个核心NPC腐化或失踪
Day 14   封印危急 —— 深潜者大潮，海面沸腾
Day 21   封印濒危 —— 疯狂之夜，天空呈现不应存在的颜色
Day 28   封印破碎 —— 末日钟声，强制终局
```

## 技术规格

### 架构

React（CDN加载）+ useReducer 全状态驱动。Lazy-clone reducer模式实现嵌套对象的按需浅拷贝。所有reducer通过 `{GD}` context访问游戏数据单例，无全局变量依赖。事件选择、结局判定、效果应用全部由JSON配置数据驱动。

V2事件调度器（`selectEventV2`，534行）支持30余种触发条件筛选、每日事件类别预算控制、独立冷却时间追踪、章节节奏约束。

### 构建流程

`build.py` 将源码打包为自包含的单文件 `index.html`：

1. 读取 HTML 模板
2. 内联样式表
3. 拼合18个reducer模块（剥离ES module语法）
4. 读取并内联主逻辑（剥离import语句）
5. 压缩合并游戏数据JSON与12个外部事件文件
6. 可选Babel JSX编译
7. 输出至 `index.html`

```bash
python build.py              # 标准构建（优先Babel CLI）
python build.py --no-babel   # 降级构建（Babel standalone CDN）
```

### 视觉系统

四字体分层架构：Noto Serif SC（叙事文本）/ Noto Sans SC（界面）/ JetBrains Mono（系统消息）/ LXGW WenKai（私人笔记）。死亡叙事块使用专用 `.death-narrative` CSS类，衬线体渲染，`letter-spacing: 0.03em`。

UI腐败动画三层递进（corruption 1-3）：文字阴影偏移 → 高频闪烁 → 模糊与饱和度衰减。SAN视觉反馈两级（tremor微颤 / fracture不规则抖动）。转场动画覆盖移动、休息、日期推进、SAN骤降、物理死亡黑屏、精神死亡扭曲共14组关键帧序列。

### 性能与无障碍

React.memo组件级缓存（四主面板）。useMemo计算级缓存（区域连通性、在场NPC列表、结论进度、死亡回放构建等）。无障碍面板提供音频全局静音、突发音效独立开关、视觉特效总开关、三级失真程度预设。
