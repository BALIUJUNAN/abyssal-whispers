## 核心系统

### 理智与认知污染

SAN值不是简单的血条，而是一个认知稳定度指标。随着SAN下降，游戏本身开始对你撒谎。

| SAN范围 | 阶段 | 表现 |
|---------|------|------|
| 80-100 | 认知稳定 | 世界按你理解的方式运转 |
| 60-79 | 轻微污染 | 偶尔错字、幻听、NPC说出不该知道的话 |
| 40-59 | 感知污染 | 地图名称变化、选项被认知改写、日志出现陌生笔迹 |
| 20-39 | 解释权丧失 | 看到不存在的选项、存档名改变、NPC用错误名字称呼你 |
| 1-19 | 现实崩解 | UI像某个存在在说话、事件否认你的记忆 |

**感知腐败系统**综合 SAN、轮回次数、神话知识、安全屋污染和当前区域五个维度，产生文字扭曲、焦点偏移、边缘泛光等多层视觉效果。

**第四面墙事件**：SAN极低时触发假存档提示、假错误信息、物品描述篡改——游戏用UI本身作为恐怖载体。

**元叙事事件（36个）**：从第5次轮回开始，按螺旋式恐惧阶梯逐步解锁：

| 轮回 | 事件类型 | SAN条件 | 示例 |
|------|---------|---------|------|
| 5+ | UI污染（10个） | ≤30 | 笔记本上未写的字蠕动、声音倒着播放、枯枝消失 |
| 6+ | 系统消息伪造（8个） | ≤20 | 虚假存档、假错误代码、连接断开10秒后街上少了一个人 |
| 7+ | 选择消失（6个） | ≤15 | 未选择的路被删除、未来概念溶解、可能性被掐灭 |
| 8+ | 身份揭示（5个） | ≤15 | 手背浮现代码、NPC被系统静音、闭眼看到屏幕另一边 |
| 9+ | 存档干预（4个） | ≤10 | 存档被篡改、文件被删除、退出按钮上有别人的指纹 |
| 10+ | 作者低语（3个） | ≤5 | "你做得很好。继续。"——然后声音消失 |

### 轮回系统

"知道真相"本身就是诅咒。

- **继承**：30%技能记忆、暗道位置、NPC弱点、已推导的结论、人性值
- **代价**：SAN上限递减、世界污染递增、NPC开始认出你
- **轮回恩赐**：每次轮回获得独特奖励（知识解锁、NPC信任加成、跳过开篇等）
- **死亡回声闭环**：死亡文本预告（"水面上会漂着一件外套"）→ 下一周目回声兑现（"水面上漂着一件外套……你知道口袋里有什么"）
- **跨周目记忆**：`buildPreviousRunSummary` 保留上一周目的关键叙事片段

| 轮回次数 | 世界反应 |
|---------|---------|
| 第1次 | 你第一次来到沃切斯特 |
| 第2次 | 你好像来过这里 |
| 第3次 | NPC开始感到似曾相识 |
| 第5次+ | NPC直说"你又来了" |
| 第8次+ | 世界开始删除不属于这里的路 |
| 第10次+ | 第600个事件自行显现 |

### 死亡系统

**15种具体死亡类型**，每种都有四段式文学级叙事：

1. **标题**（你死于溺水。）
2. **最后时刻**（第一人称沉浸式感官描写）
3. **世界处理**（冷视角——世界对你死亡的冷淡处理）
4. **轮回残留**（下一周目的污染预告）

死亡类型推理链：`death_hint`（事件指定）> tags 匹配 > 区域启发式 > 默认。HP死亡（溺水/失血/感染/饥饿/坠落/黑暗吞噬）和SAN死亡（疯狂/附身/身份抹除/神话吞噬/循环崩塌/成为事件）各有完全不同的文本风格。

死亡叙事使用**专属衬线字体**渲染（Noto Serif SC，`line-height: 1.9`），与系统消息的等宽灰斜体形成明确对比。首次物理死亡有2秒黑屏渐隐动画，首次精神死亡有2秒视觉扭曲动画。

### NPC信任与救赎

每位核心NPC拥有6级信任系统（每级含数百字完整对白）、腐化触发器和独立的救赎路径。

| NPC | 身份 | 特殊机制 |
|-----|------|---------|
| 玛莎·格雷 | 酒吧老板 | 安全屋核心，信任3级解锁港口情报 |
| 老费舍 | 渔夫 | 古老血脉秘密，拥有逃离港口的关键 |
| 希尔达·莫里斯 | 庄园女主人 | 封印家族后裔，可选为代价承担者 |
| 伊莎贝拉·韦伯 | 教堂执事 | 异端知识持有者，救赎路径独特 |
| 约书亚·布莱克 | 退伍军人 | 战争创伤与信仰困境 |
| 伊莱亚斯·沃德 | 学者 | 神话知识来源，可解锁深层区域 |
| 汤米·陈 | 报童 | 城市消息网络，侦察线索加成 |
| 拉维尼亚·沃德 | 画家 | 感知异常者，能看到不该看到的东西 |

NPC对话选项：建立信任 / 询问情报 / 分享食物 / 尝试救赎 / 沉默 / 告别。沉默也会影响人性值——不回答本身就是回答。

### 探索与SAN赌博

每次探索消耗2AP，触发一个随机事件。25%概率触发"深入探究"选择：

- **收手**：承受正常SAN损失，安全离开
- **继续观察**：额外SAN风险（1d6），但可能获得隐藏线索——或触发临时疯狂，被"某种东西"记住

### 结局系统

结局由三个维度共同决定：

1. **世界结果**：封印重铸 / 逃离 / 深渊胜利 / 超越 / 轮回破壁
2. **代价承担者**：玩家 / NPC / 共同承担 / 无人
3. **人性判定**：尚存人性 / 人性脆弱 / 人性迷失

四层结局叙事生态：

| 层 | 名称 | 触发条件 |
|----|------|---------|
| 1 | 结局预兆 | 接近结局条件时出现的暗示性事件 |
| 2 | 结局达成 | 满足条件后触发的正式结局 |
| 3 | 结局余波 | 上一周目的结局在下一周目留下的回响 |
| 4 | 结局交织 | 见过多种结局后解锁的元叙事层 |

### 封印倒计时

城市有自己的生命周期，28天从"完整"走向"崩碎"：

```
Day 1    封印完整 → 钟声异常，失踪告示出现
Day 7    封印松动 → 第一个NPC腐化或失踪
Day 14   封印危急 → 深潜者大潮，海面沸腾
Day 21   封印濒危 → 疯狂之夜，天空变红
Day 28   封印破碎 → 末日钟声，强制终局
```

## 构建说明

`build.py` 将 `src/` 下的所有源文件打包为单个 `index.html`。

### 前置要求

- **Python 3.6+**（必须）
- **Babel**（可选）：`npx babel` 可用时编译 JSX，否则使用 Babel standalone CDN

### 构建命令

```bash
# 标准构建（尝试使用 Babel CLI）
python build.py

# 降级构建（使用 Babel standalone CDN）
python build.py --no-babel
```

### 构建流程

1. 读取 `src/index.template.html` 模板
2. 内联 `src/styles.css`
3. 拼接 18 个 `src/reducers/*.js` 模块（剥离 ES module 语法）
4. 读取 `src/app.jsx`（剥离 import 语句）
5. 读取 `src/game_data.json` + 12 个外部事件文件（压缩为一行 JSON）
6. 合并所有 JS，可选通过 Babel 编译 JSX
7. 输出单文件 `index.html`

## 技术实现

### 架构

- **React**（CDN）+ **useReducer** 驱动所有状态
- **Lazy-clone** reducer 模式：按需克隆嵌套对象，避免不必要拷贝
- **ctx = {GD}** 模式：所有 reducer 通过 context 访问游戏数据，无全局依赖
- **数据驱动**：事件选择、结局判定、效果应用全部由 JSON 配置驱动
- **V2 事件调度器**（`selectEventV2`）：支持 30+ 触发条件、每日类别预算、冷却时间、章节节奏控制

### 死亡系统架构

三层分离设计：

```
事件触发死亡
    ↓
resolveDeath(state, event, choice)
    ↓
inferDeathType()  ← 5层优先级推理链
  1. death_hint（事件直接指定）
  2. tags 匹配（事件标签）
  3. SAN/HP 模式分类
  4. 区域启发式
  5. 默认值
    ↓
getDeathText()  ← 四段式文学文本生成
  1. title: "你死于溺水。"
  2. lastMoment: 第一人称沉浸式
  3. worldHandles: 冷视角处理
  4. residue: 下一周目污染预告
    ↓
residueFlag → death_echo_xxx → 下周目回声事件兑现
```

### 视觉系统

- **四字体分层**：Noto Serif SC（叙事）/ Noto Sans SC（UI）/ JetBrains Mono（系统）/ LXGW WenKai（私人文本）
- **死亡叙事专属样式**：`.death-narrative` 类使用衬线体渲染，`font-style: normal`，`letter-spacing: 0.03em`
- **UI腐败层**（corruption 1-3）：文字阴影、闪烁、模糊、饱和度递减
- **SAN视觉**（san-tremor / san-fracture）：叙事文本微颤抖/不规则抖动
- **感知腐败**（perception-focus/edge/text 1-3）：五个维度独立控制
- **转场动画**：移动黑屏渐隐、休息长时间黑屏+日期显示、SAN损失红色径向渐变
- **死亡动画**：物理死亡黑屏（`deathBlackout`）、精神死亡视觉扭曲（`deathDistort`）

### 性能优化

- **React.memo** 组件级（LeftPanel / CenterPanel / RightPanel / NarrativeBlock）
- **useMemo** 计算级（连接区域、在场NPC、结论进度、死亡回放等）
- **Lazy-clone** 仅克隆当前 action 实际修改的数组/对象

### 无障碍

游戏内置三项无障碍开关：

- 🔊 音频静音 / 关闭突发音效（SAN骤降、破壁音效）
- 👁 关闭视觉特效（SAN震动/模糊/腐败闪烁/感知扭曲）
- 三种失真程度预设（low / medium / off）
