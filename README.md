## 你踏入了什么

1926 年深秋。马萨诸塞州东南海岸。一座叫沃切斯特的港口城市。

你来这里的原因不重要——失踪案委托、学术邀请、或者只是在错误的时间出现在了错误的地点。

重要的是：**一旦踏入这座城，你就再也无法轻易离开。**

### 这座城不对劲

教堂的钟声每天敲响 **十三下**。码头的潮汐与任何时刻表都不吻合。公告栏上贴着你的失踪告示——上面的照片是你，但你还没拍过那张照。

三百年前莫里斯家族在此建立了封印。三百年后，封印开始松动。

深潜者从海岸裂隙中爬出。夜魔在森林中低语。地下墓穴里传来有节奏的敲击声——仿佛某个庞然之物正在苏醒。

### 你会遇到这些人

| 角色 | 身份 | 你需要知道的 |
|------|------|-------------|
| 老费舍 | 渔夫 | 打了六十年的鱼。血管里流着不属于人类的东西。他知道的比你想象的多 |
| 玛莎·格雷 | 酒吧老板娘 | 镇上唯一不问来处的女人。吧台最右边那杯没动过的酒，她每天换一杯新的 |
| 希尔达·莫里斯 | 庄园女主人 | 封印家族最后一位直系后裔。二十八岁。已经能感觉到来自地下的拉扯 |
| 伊莎贝拉·韦伯 | 教堂执事 | 每天敲响十三下钟声的人。皮肤下偶尔能看到蠕动的纹路 |
| 伊莱亚斯·沃德 | 退休教授 | 能读不该读的文字。代价是理智以可测量速度流失 |
| 约书亚·布莱克 | 流浪汉 | 前海军陆战队员。失踪一周后被发现时蜷缩在垃圾桶旁。身上的螺旋形疤痕不是战场上留下的——是在这座城留下的 |
| 汤米·陈 | 杂货店主 / 业余摄影师 | 冲洗出来的照片里总有些不该存在的影子。出于好奇心反而拍得更勤了 |
| 埃德加·洛夫克拉夫特 | 作家 | 偶尔介入调查的记录者 |

每位 NPC 有 **6 层对话树**，每一层的文本完全重写——不是态度变化，是对话逻辑本身重组。

**沉默也是一种选择。** 不回答玛莎的问题，她反而更信任你了。在这个镇上，不说话有时候是最安全的回答。

第八周目的时候，老费舍会对你说：

> "你又来了。"

五个字。然后你会关掉浏览器，坐很久。

## 深渊机制

### 核心循环

```
每日行动点 → 探索 / 对话 / 调查 / 工作或隐秘行动
        ↓
   触发事件（技能检定 d100）
        ↓
  HP 归零 = 死亡 → 进入下一周目
  SAN 归零 = 疯狂 → 进入下一周目
        ↓
  保留知识碎片与世界污染记录
  SAN 上限永久削减
  再次踏入沃切斯特
```

### 理智值 (SAN)：这不是血条

SAN 是你与现实之间的契约强度。数值下降时，**游戏本身开始对你撒谎：**

| SAN 区间 | 临床记录 | 游戏表现 |
|----------|---------|---------|
| **80-100** | 认知稳定 | 一切正常。你还相信自己看到的东西 |
| **60-79** | 轻度侵蚀 | 文字偶尔出现微弱阴影。你可能注意到了，也可能没有 |
| **40-59** | 感知偏移 | 叙事文本开始颤抖。按钮响应变慢。区域名称泛着不自然的光晕 |
| **20-39** | 解释权丧失 | UI 本身在对抗你。选项文字会自己改写。存档文件名变了 |
| **1-19** | 现实崩解 | 第四面墙破裂。伪造存档通知、注入虚假错误代码、篡改物品描述 |

**这不是"角色疯了所以看到幻觉"的廉价处理。是界面本身成为恐怖载体。**

### 28 天封印倒计时

| 时间节点 | 发生了什么 |
|----------|-----------|
| Day 1 | 钟声开始异常 |
| Day 7 | 核心NPC开始出现腐化征兆 |
| Day 14 | 深潜者大潮登陆 |
| Day 21 | 全城疯狂之夜 |
| Day 28 | 封印破碎 —— 最终决战 |

每次轮回都更难。SAN 上限削减 3 点。NPC 逐步识别你是重复访客。

### 死亡不是终点

14-15 种死亡类型 × 4 段独立叙事结构 = **60 段死亡文本，零复用模板**：

```
判词 → 终末 → 处理 → 残响
```

死亡描述可能是第一人称意识流。读完之后你才意识到角色已经不在了。

而上一周目的死法会在下一周目以 **"回声事件"** 形式回归——你在第五周目码头边看到了自己第一次溺水的痕迹。一件漂着的外套。口袋里有不该存在的东西。

### 你能达成哪些结局

| 类别 | 数量 | 说明 |
|------|------|------|
| 主线结局 | 10 条 | 真/隐藏/好/坏/中性，根据人性值分支 |
| Meta 隐藏结局 | 1 条 | 第 599 个事件尽头打破第四面墙 |
| 行为/异常结局 | **36 条** | 由你的行为模式触发——自残/融合/食人/背叛/救赎……每种都有独立路径 |
| 死亡终局 | 15 种 | 四段式叙事独立撰写 |
| 结局辅助事件 | 71 个 | 预兆 / 余波 / 交织 / 回声 |

**7 种起始职业**决定初始属性和特殊能力：记者 / 渔夫 / 学者 / 军医 / 侦探 / 牧师 / 流亡者

三周目以内不可能看完所有内容。五周目以上才开始理解世界的真实运作方式。十周目以上才有可能触达 Meta 隐藏结局。

预计完整体验：**20-40 小时**。

## 技术档案

> 以下内容面向开发者与对交互叙事工程感兴趣的研究者。

### 架构总览

```
React 18 (CDN) + useReducer 全状态驱动
         ↓
    Lazy-clone Reducer 模式（嵌套对象按需浅拷贝）
         ↓
    {GD} Context 单例（游戏数据全局访问，无全局变量污染）
         ↓
    JSON/JS 配置驱动（事件/结局/效果/NPC 全部数据化）
         ↓
单文件构建产物 index.html (~2.2 MB, 完全离线)
```

### 核心模块一览

| 层级 | 模块 | 职责 | 数据规模 |
|------|------|------|---------|
| **状态管理** | 18 个 Reducer | san / death / loop / npc / ending / save / event / effect / world / ... | ~4000 行 |
| **事件引擎** | V2 调度器 | 30+ 触发条件、预算控制、冷却追踪、章节约束 | 534 行核心逻辑 |
| **死亡系统** | 五层推理链 | 事件指定 → 标签匹配 → 模式分类 → 区域启发式 → 默认兜底 | 381 行 |
| **SAN 系统** | 认知污染引擎 | UI 层文字扭曲/滤镜衰减/DOM注入/第四面墙突破 | 多层 CSS + JS |
| **轮回系统** | 跨周目状态传递 | 世界恶化 / NPC记忆 / 死亡回声 / SAN上限削减 | 跨 reducer 协调 |
| **素材系统** | portraitMap.js | 210 张 WebP 素材映射（立绘/场景/结局CG/事件插图） | 100% 使用率 |
| **音频系统** | audioManager | 6 个音效文件 + BGM 循环 + SAN 联动音量调制 | 7.9 MB |

### V2 事件调度器决策链

```
1. 章节约束检查（当前章节允许的事件类别）
       ↓
2. 区域过滤（当前所在区域的事件池）
       ↓
3. 触发条件评估（30+ 种：SAN阈值 / 轮回次数 / NPC状态 / 道具持有 / 人性值 ...）
       ↓
4. 日预算控制（每类事件每日上限，防止同类刷屏）
       ↓
5. 独立冷却追踪（每个具体事件的最低间隔）
       ↓
6. 加权随机抽取（权重 = 基础权重 × 当前条件系数）
```

### 数据驱动设计

所有叙事内容由数据文件定义，非硬编码。**新增事件不需要改动任何 reducer 代码**：

```
src/data/
├── events_loop.js           # 轮回专属（70 事件）
├── events_ending.js         # 结局预兆/余波/交织（55 事件）
├── events_humanity.js       # 人性值驱动（60 事件）
├── events_mythos.js         # 神话知识（62 事件）
├── events_npc_cross.js      # NPC 交叉互动（67 事件）
├── events_resource.js       # 资源管理（57 事件）
├── events_silent.js         # 沉默事件（84 事件）
├── events_area_deep.js      # 深层区域探索（121 事件）— 最大模块
├── events_death_echo.js     # 死亡回声（17 事件）
├── events_meta.js           # 元叙事破壁（36 事件）
├── events_missing_600.js    # 隐藏虚拟事件（1 事件）
├── ending_missing_600.js    # 第 600 事件结局
├── behavior_endings.js      # 36 个行为结局定义 + 条件
└── game_data.json            # 世界规则/NPC/道具/区域/主线结局（~550 KB）
```

### 字体与视觉架构

四层字体系统，用排版传达信息类别：

| 字体 | 用途 | 示例场景 |
|------|------|---------|
| Noto Serif SC | 叙事层 | 事件描述、NPC 对话、死亡叙事 |
| Noto Sans SC | 界面层 | 按钮、面板标题、状态栏 |
| JetBrains Mono | 系统层 | 日志、错误提示、元叙事破壁文本 |
| LXGW WenKai | 笔记层 | 私人笔记、线索档案、手写遗书 |

UI 污染三层递进（CSS class: `.corruption-1` / `corruption-2` / `corruption-3`）：

| 污染等级 | 视觉效果 |
|---------|---------|
| Level 1 | 文字微弱阴影偏移 + 边缘泛光 |
| Level 2 | 高频闪烁 + 色相漂移 + 按钮延迟 |
| Level 3 | 模糊衰减 + 不规则抖动 + 扭曲滤镜 + 选项文字自我改写 |

SAN 两级视觉反馈：`.san-tremor`（叙事区微颤）→ `.san-fracture`（不规则抖动+模糊）。

转场动画共 **14 组关键帧**：移动黑场 / 日期推进 / SAN骤降红闪 / 物理死亡渐暗 / 精神死亡扭曲 ...

### 构建流程

```bash
python build.py              # 标准构建（Babel CLI 编译 JSX → ~2.2MB）
python build.py --no-babel   # 降级构建（Babel standalone CDN → 更大但兼容性更好）
```

构建步骤：HTML模板 → 内联CSS → 拼合18个reducer → 内联app.jsx → 合并事件数据(~510KB) → Babel编译 → 输出单文件index.html

### 性能与兼容性

- React.memo 组件级缓存（四大主面板）
