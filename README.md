## ⚙️ 核心系统

### 理智与认知污染

SAN值不是简单的血条，而是一个认知稳定度指标。随着SAN下降，游戏本身开始对你撒谎。

| SAN范围 | 阶段 | 表现 |
|---------|------|------|
| 80–100 | 认知稳定 | 世界按你理解的方式运转 |
| 60–79 | 轻微污染 | 偶尔错字、幻听、NPC说出不该知道的话 |
| 40–59 | 感知污染 | 地图名称变化、选项被认知改写、日志出现陌生笔迹 |
| 20–39 | 解释权丧失 | 看到不存在的选项、存档名改变、NPC用错误名字称呼你 |
| 1–19 | 现实崩解 | UI像某个存在在说话、事件否认你的记忆 |

**第四面墙事件**：SAN极低时触发假存档提示、假错误信息、物品描述篡改。

### 轮回系统

"知道真相"本身就是诅咒。

- **继承**：30%技能记忆、暗道位置、NPC弱点、已推导的结论
- **代价**：SAN上限递减、世界污染递增、NPC开始认出你

| 轮回次数 | 世界反应 |
|---------|---------|
| 第1次 | 你第一次来到沃切斯特 |
| 第2次 | 你好像来过这里 |
| 第3次 | 你确定来过这里 |
| 第5次+ | 你就是沃切斯特的一部分 |

### NPC信任与救赎

每位核心NPC拥有5级信任系统、腐化触发器和独立的救赎路径。救赎不等于存活——而是在不可逆腐化中保留最后一次人性选择。

### 结局判定

结局由三个维度共同决定：

1. **世界结果**：封印重铸 / 逃离 / 深渊胜利 / 超越 / 轮回破壁
2. **代价承担者**：玩家 / NPC / 共同承担 / 无人
3. **人性判定**：尚存人性 / 人性脆弱 / 人性迷失

### 封印倒计时

城市有自己的生命周期，28天从"完整"走向"崩碎"：

```
Day 1    封印完整 → 钟声异常，失踪告示出现
Day 7    封印松动 → 第一个NPC腐化或失踪
Day 14   封印危急 → 深潜者大潮，海面沸腾
Day 21   封印濒危 → 疯狂之夜，天空变红
Day 28   封印破碎 → 末日钟声，强制终局
```

## 🔧 构建说明

`build.py` 将 `src/` 下的所有源文件打包为单个 `index.html`。

### 前置要求

- **Python 3.6+**（必须）
- **Babel**（可选）：`npx babel` 可用时编译 JSX，否则使用 Babel standalone CDN

### 构建命令

```bash
# 标准构建（尝试使用 Babel CLI）
python build.py

# 降级构建（使用 Babel standalone CDN）
python build.py --no-babel
```

### 构建流程

1. 读取 `src/index.template.html` 模板
2. 内联 `src/styles.css`
3. 拼接 14 个 `src/reducers/*.js` 模块（剥离 ES module 语法）
4. 读取 `src/app.jsx`（剥离 import 语句）
5. 读取 `src/game_data.json`（压缩为一行 JSON）
6. 合并所有 JS，可选通过 Babel 编译 JSX
7. 输出单文件 `index.html`

## 🛠️ 开发指南

### 架构原则

- **`ctx = {GD}` 模式**：所有 reducer 通过 `ctx` 参数访问游戏数据，无全局变量依赖
- **数据驱动**：事件选择、结局判定、效果应用全部由 `game_data.json` 配置驱动
- **不可变更新**：reducer 在函数入口处克隆嵌套对象/数组

### 数据结构

`game_data.json` 是唯一的数据源（~550KB），包含：

- 9个区域、6+个NPC、97个事件、70+种道具
- 5个章节定义、10+个结局（含30段人性变体文本）
- 线索链、结论系统、安全屋退化、轮回污染
- 艺术方向、感官污染规则、UI腐败层级
- 恐怖密度控制、章节美术节奏、沉默事件池

### 无障碍

游戏内置三项无障碍开关：

- 🔊 音频静音
- ⚡ 关闭突发音效
- 👁 关闭视觉特效（SAN震动/模糊/腐败闪烁）
