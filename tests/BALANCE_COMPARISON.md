## 🔧 v3 调整建议

基于v2的问题，提出以下调整方案：

### 1. 降低SAN保护强度

```javascript
// v2: Day 1-3: 70% reduction
// v3建议: Day 1-3: 50% reduction
function applyDayProtection(sanLoss, day) {
  if (day <= 3) return Math.max(1, Math.round(sanLoss * 0.5)); // 从0.3改为0.5
  if (day <= 7) return Math.max(1, Math.round(sanLoss * 0.7)); // 从0.5改为0.7
  if (day <= 14) return Math.max(1, Math.round(sanLoss * 0.85)); // 从0.75改为0.85
  return sanLoss;
}
```

## 💡 核心洞察

1. **SAN和HP需要平衡保护**
   - 只保护SAN会导致HP成为唯一死因
   - 需要同时保护两者，但强度不同

2. **保护机制需要分阶段**
   - Day 1-7: 强保护（教学期）
   - Day 8-14: 中等保护（适应期）
   - Day 15-21: 弱保护（挑战期）
   - Day 22-28: 无保护（高潮期）

3. **曲线形状比绝对值更重要**
   - 目标是平缓下降，而不是保持高值
   - SAN应该从60缓慢降到25-35，而不是保持在43+

4. **配置平衡性需要独立调整**
   - 恐惧画像、职业、人格的差异过大
   - 需要为每个配置设置独立的保护参数

---

**结论**: v2成功改善了SAN曲线，但引入了HP死亡问题。v3需要同时保护SAN和HP，并进一步降低探索风险。
