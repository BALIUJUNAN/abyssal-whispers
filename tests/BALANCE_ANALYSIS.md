## 🚨 关键问题

### 1. Day 1-7 (封印完整期) SAN损失过重

**问题**: 
- Day 1-7 平均SAN损失 **47点**（从60降到13）
- 每天平均损失 **6.7点SAN**
- 这个阶段应该是"安全期"，但实际几乎致命

**原因分析**:
- 探索事件SAN伤害系数过高
- 封印完整期的 `san_loss_multiplier: 0.8` 没有生效
- 恐惧画像加成过于激进

**建议**:
```javascript
// 降低Day 1-7的基础SAN损失
// 当前: 0.3 + danger * 0.1 = 0.3 + 1 * 0.1 = 0.4 (40%概率)
// 建议: 0.15 + danger * 0.05 = 0.15 + 1 * 0.05 = 0.2 (20%概率)

// 或者添加Day 1-7保护机制
if (s.day <= 7) {
  sanLossMultiplier *= 0.5; // Day 1-7 SAN损失减半
}
```
