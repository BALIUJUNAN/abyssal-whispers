# Vite Smoke Checklist

每次 Vite 相关 PR 合并前，必须在浏览器中手动完成以下流程。

## 前置条件

```bash
npm install
npm test            # 全量测试
npm run dev         # 启动 Vite dev server
```

浏览器打开 http://localhost:3000

---

## 1. 标题画面

- [ ] 页面不是空白
- [ ] 不是 "ES 模块渐进迁移中" 占位页
- [ ] 能看到游戏标题 "深渊低语"
- [ ] 副标题 "沃切斯特之影" 可见
- [ ] 轮播标语正常切换（约 8 秒一次）
- [ ] "踏入深渊" 按钮可见
- [ ] 设置齿轮 ⚙️ 和成就 🏆 按钮可见
- [ ] Console 无红色 runtime error

## 2. 新游戏

- [ ] 点击 "踏入深渊" 后标题淡出
- [ ] 进入序章 / 角色创建画面（非空白、非标题页卡住）
- [ ] 可以正常完成角色创建流程
- [ ] 进入主游戏界面（地图、面板、事件区可见）

## 3. 第一个事件

- [ ] 进入游戏后，中心区域显示事件叙事文本
- [ ] 事件选项按钮可点击
- [ ] 点击选项后，文本更新（不卡死）

## 4. 触发一次选择

- [ ] 点击事件选项后，结果文本显示
- [ ] SAN / 资源数值有变化（面板数值更新）
- [ ] Console 无新增红色错误

## 5. 打开设置

- [ ] 点击 ⚙️ 按钮
- [ ] 设置弹窗出现（音量、字体大小等选项）
- [ ] 调整任意设置（如字体大小），效果即时生效
- [ ] 关闭设置弹窗，回到游戏

## 6. 保存

- [ ] 打开存档界面（SaveLoadModal）
- [ ] 选择一个存档槽位保存
- [ ] 保存成功提示出现（toast 通知）
- [ ] Console 无红色错误

## 7. 刷新页面

- [ ] 按 F5 / Ctrl+R 刷新浏览器
- [ ] 页面重新加载，不是空白
- [ ] 标题画面正常显示
- [ ] "翻阅旧档案" 按钮出现（因为有存档）
- [ ] Console 无红色错误

## 8. 读档

- [ ] 点击 "翻阅旧档案"
- [ ] 存档列表显示刚才保存的进度
- [ ] 点击加载，恢复到保存时的游戏状态
- [ ] 天数、SAN、物品等数值与保存时一致
- [ ] Console 无红色错误

## 9. 返回主界面

- [ ] 在游戏界面中可以回到标题画面（如通过存档读取标题页，或刷新）
- [ ] 标题画面正常，无残余游戏状态泄露

## 自动化边界

本清单为手动验收。以下场景不适合自动化：

- CSS 视觉渲染（淡出动画、粒子效果）
- 音频播放
- SAN 腐蚀视觉效果
- 模态框 z-index 层级

可自动化的部分（未来 PR）：

- 页面加载不报错
- 关键 DOM 元素存在
- 存储 API 可调用
