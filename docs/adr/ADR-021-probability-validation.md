# ADR-021: 数值设计必须跑概率分布

**日期**: 2026-06-16
**状态**: 已采纳

## Context

SAN 开局值公式 `POW = 3d6×5` 看起来合理（平均 52.5），但没有模拟骰子分布。
20% 概率 < 40，直接进入高阶腐蚀。

## Decision

1. 数值设计必须用概率分布验证，不能只看公式
2. 写完骰子公式立即跑 1000 次模拟
3. 添加下界保护：`s.san = Math.max(40, s.san)`

## Consequences

- ✅ 极端值不会破坏游戏平衡
- ✅ 数值设计有数据支撑
- ⚠️ 需要维护模拟脚本
