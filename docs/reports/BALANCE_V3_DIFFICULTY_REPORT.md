# 28天平衡性测试 v3 多难度模式对比报告

**测试时间**: 2026-06-17  
**测试规模**: 500次模拟 (每个难度)  
**随机种子**: 42  

---

## 📊 难度模式总览

| 难度 | 存活率 | 平均天数 | 平均SAN | 平均HP | 评价 |
|------|--------|----------|---------|--------|------|
| **Easy** | 44.8% | 23.31天 | 91.82 | 4.03 | ✅ 超过目标 |
| **Normal** | 19.2% | 19.02天 | - | - | 🟡 接近目标 |
| **Hard** | 6.0% | 13.36天 | - | - | 🔴 低于目标 |
| **Nightmare** | 2.2% | 8.32天 | - | - | 🔴 高难度 |

**目标**: Normal模式存活率30-40%，平均20-25天

---

## 🎯 详细分析

### Easy模式 (休闲玩家)

**配置特点**:
- SAN保护: Day 1-3: 70%, Day 4-7: 50%, Day 8-14: 30%
- HP保护: Day 1-3: 70%, Day 4-7: 50%, Day 8-14: 30%
- 最大SAN损失: 2/行动, 6/天
- 最大HP损失: 1/行动, 3/天
- 安全区: Day 1-7禁止访问danger>=4区域
- 每2天恢复: SAN+2, HP+1

**结果**:
- 存活率: 44.8% ✅
- 平均天数: 23.31天 ✅
- SAN曲线: 60 → 97 (上升！) 🟡
- HP死亡: 276次, SAN死亡: 0次

**问题**: SAN保护过度，玩家SAN反而上升

---

### Normal模式 (标准难度)

**配置特点**:
- SAN保护: Day 1-3: 50%, Day 4-7: 30%, Day 8-14: 15%
- HP保护: Day 1-3: 50%, Day 4-7: 30%, Day 8-14: 15%
- 最大SAN损失: 3/行动, 8/天
- 最大HP损失: 2/行动, 4/天
- 安全区: Day 1-5禁止访问danger>=4区域
- 每3天恢复: SAN+1, HP+1

**结果**:
- 存活率: 19.2% 🟡 (目标30-40%)
- 平均天数: 19.02天 ✅ (目标20-25天)
- HP死亡: 404次, SAN死亡: 0次

**问题**: 存活率偏低，需要微调

---

### Hard模式 (挑战难度)

**配置特点**:
- SAN保护: Day 1-3: 30%, Day 4-7: 15%, Day 8-14: 5%
- HP保护: Day 1-3: 30%, Day 4-7: 15%, Day 8-14: 5%
- 最大SAN损失: 4/行动, 10/天
- 最大HP损失: 3/行动, 5/天
- 安全区: Day 1-3禁止访问danger>=5区域
- 每4天恢复: SAN+1

**结果**:
- 存活率: 6.0% 🔴
- 平均天数: 13.36天 🔴
- HP死亡: 458次, SAN死亡: 12次

**评价**: 适合喜欢挑战的玩家

---

### Nightmare模式 (原始v1难度)

**配置特点**:
- SAN保护: 无 (100%损失)
- HP保护: 无 (100%损失)
- 最大损失: 无限制
- 探索SAN概率: 30% + danger * 10%
- 安全区: 无

**结果**:
- 存活率: 2.2% 🔴
- 平均天数: 8.32天 🔴
- HP死亡: 445次, SAN死亡: 44次

**评价**: 保留作为高难度模式，原汁原味的克苏鲁体验

## 🔧 Normal模式调整建议

当前Normal模式存活率(19.2%)低于目标(30-40%)，建议微调：

### 方案A: 增加保护强度
```javascript
normal: {
  san_protection: { day_1_3: 0.4, day_4_7: 0.6, day_8_14: 0.8, day_15_21: 0.9 },
  hp_protection: { day_1_3: 0.4, day_4_7: 0.6, day_8_14: 0.8, day_15_21: 0.9 },
  // ... 其他配置不变
}
```

### 方案B: 增加恢复
```javascript
normal: {
  day_recovery: { interval: 2, san: 1, hp: 1 },  // 从3天改为2天
  rest_san_recovery: 3,  // 从2改为3
  // ... 其他配置不变
}
```

### 方案C: 降低探索风险
```javascript
normal: {
  explore_san_chance: 0.10,  // 从0.12降低
  explore_danger_mult: 0.03, // 从0.04降低
  monster_hp_chance: 0.06,   // 从0.08降低
  // ... 其他配置不变
}
```

   - Normal: 标准挑战 (19%存活)
   - Hard: 硬核挑战 (6%存活)

3. **需要微调Normal模式**
   - 当前19%存活率低于目标30-40%
   - 需要找到"有挑战但不挫败"的平衡点

4. **Nightmare模式保留原汁原味**
   - 作为高难度选项
   - 满足硬核玩家需求
