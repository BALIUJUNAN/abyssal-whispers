# 事件编写指南

## 核心规则

### 1. ID 引用（不是中文名）

```
NPC 引用:    "martha_grey"     不要 "玛莎·格雷"
区域引用:    "harbor_district"  不要 "码头区"
物品引用:    "silver_dagger"    不要 "银质匕首"
```

查 ID：`node -e "console.log(require('./src/data/registry/npcRegistry.cjs').NPC_REGISTRY)"`

### 2. effects 只能使用注册过的 type

```
合法: HP, san, food, items, add_flag, add_clue, add_item, npc_trust,
      safehouseCorruption, add_run_memory, mythos, humanity, _meta_effect

非法: 任何未注册的 key 会导致 E03 警告
```

### 3. conditions 结构

```
合法: "player_san <= 0"
合法: "completed_clue_chains >= 2"
合法: "has_key_blood OR has_alternative_seal"

规则:
  - OR/AND 必须大写
  - 括号必须配对
  - 不能有空条件
```

### 4. 新增债务会 FAIL

构建时 `python build.py --prod` 会运行验证器。如果新增了：

- 未注册的 NPC/物品引用 → E14/E15 ERROR
- 超过 baseline 的中文引用 → E11_BASELINE/E12_BASELINE ERROR

```json
{
  "id": "evt_harbor_021",

  },

}
```

## NPC 语言指纹规范

> 每条规则包含：语气特征、句式偏好、高频意象、禁用表达。
> 新增台词前对照对应 NPC 的指纹，确保同一角色的台词可被玩家凭语气辨识。

### 老费舍（Old Fisher）

| 维度 | 规则 |
|------|------|
| 句式 | 极短陈述句为主。大量无台词的舞台指示：`（他没有抬头。手里的渔网在修补。）` |
| 语气 | 寡言、粗糙、近乎 monosyllabic。低信任时几乎不回答 |
| 高频意象 | 渔网、缆绳、锚链、潮水、1919大雾、海底呼吸声、东边的浪 |
| 信任递进 | 0:沉默修网 → 1: curt dismissal → 2:递茶 → 3:要求体力帮助 → 4:用自己的杯子 → 5:给1919年沉船缆绳 |
| 轮回记忆 | "海会记住所有回来的人" — 用海洋意象表达重复 |
| 死亡回响 | 提及"水变红又清了"，他知道原因 |
| SAN 退化 | 从"你很累"到"水面映不出你的脸" — 海洋幻觉意象递增 |
| 禁用 | 长句解释、提问（低信任时）、情感形容词 |

### 约书亚·布莱克（Joshua Black）

| 维度 | 规则 |
|------|------|
| 句式 | 战术性、祈使句优先。警告先行："小心第十三级。那级台阶的响声不对。" |
| 语气 | 军旅式简练。大量省略号 trailed off into horror |
| 高频意象 | 灯塔、楼梯/台阶、枪、战壕、码头下管道、海图、绿光 |
| 信任递进 | 0:转身不看 → 1:"灯塔不对外开放" → 2:警告第13级 → 3:递望远镜 → 4:展示秘密海图 → 5:给枪 |
| 轮回记忆 | "你让我想起了困在战壕里的日子。不是恐惧——是重复。" |
| 死亡回响 | 扶手划痕还在，和上次一模一样 |
| SAN 退化 | "你看起来几天没睡了" → "你眼睛在发光" → "你不再是人但还在假装" |
| 禁用 | 抒情独白、疑问句（非警告性）、暖色调描述 |

### 希尔达·莫里斯（Hilda Morris）

| 维度 | 规则 |
|------|------|
| 句式 | 礼貌性开场 + 恐怖内容。always starts with gesture: "门开着。进来吧。" |
| 语气 | 贵族式、克制。用建筑/艺术史词汇。优雅地描述恐怖 |
| 高频意象 | 走廊画像、地下室、庄园、1780年、门锁不住、画像手指数量 |
| 信任递进 | 0:门口沉默 → 1:请进提及画像 → 2:地下室门锁不住 → 3:画像不是装饰是记录 → 4:画像手指异常 → 5:通往码头的通道 |
| 轮回记忆 | "走廊里的画像已经认得你了。它们习惯了你。" |
| 死亡回响 | 左手旧疤（上次在 basement 摔的） |
| SAN 退化 | "你看起来很疲惫" → "走路姿势变了像在水里" → "你的影子告诉了我秘密" |
| 禁用 | 口语化、俚语、直接恐惧表达 |

### 玛莎·格雷（Martha Grey）

| 维度 | 规则 |
|------|------|
| 句式 | 随意对话体。幽默作为防御机制。"喝点什么？别站着。" "又来了？坐吧。" |
| 语气 | 酒馆老板口语。市井精明。母性 but no-nonsense |
| 高频意象 | 酒馆/杯子/啤酒、码头、失踪的丈夫、角落空桌、灯塔、1919沉船 |
| 信任递进 | 0:递饮料 → 1:那条自己开走的船 → 2:灯塔和约书亚 → 3:酒馆地下室的门 → 4:码头排水管 → 5:丈夫的秘密 |
| 轮回记忆 | "你不是客人——你是这间酒馆的一部分。" "你每次来点一样的东西，表情不一样。" |
| 死亡回响 | 你上次坐的位置永远是空的 |
| SAN 退化 | "你的影子动了一下" → 推过来一杯黑色的酒（她没注意颜色） → "我不记得你是谁但这没关系因为你明天也不记得" |
| 禁用 | 正式用语、学术词汇、直接恐怖描写 |

### 伊莱亚斯·沃德（Elias Ward）

| 维度 | 规则 |
|------|------|
| 句式 | 学术观察体。用括号插入实验笔记风格：`（他在笔记本上写了一行字，没有让你看。）` |
| 语气 | 冷静研究者。把超自然当实验对象。偶尔泄露个人关切 |
| 高频意象 | 密斯卡托尼克大学档案、1692建城、晨星、封印、体温测量、笔记本 |
| 信任递进 | 0:"新来的？" → 1:指路 → 2:请坐翻开笔记 → 3:锁门拉窗帘 → 4:封印不是人造 → 5:揭示更深层秘密 |
| 轮回记忆 | "你的档案里多了一条记录。死亡原因：……" "你上次坐那把椅子，磨损痕迹和坐姿吻合。" |
| 死亡回响 | 档案记录，冷峻地提及死亡原因但不读完 |
| SAN 退化 | "认知模式偏移" → "体温低了2度" → "你不再是案例——你是现象" |
| 禁用 | 情感宣泄、通俗比喻、非学术词汇 |

### 伊莎贝拉·韦伯（Isabella Weber）

| 维度 | 规则 |
|------|------|
| 句式 | 祈祷/布道体。用宗教框架包裹恐怖。"愿主保佑你。" "教堂建于1740年……" |
| 语气 | 虔诚但逐渐动摇。从传道者到见证者到共犯 |
| 高频意象 | 十字架（影子变化）、蜡烛（数量异常）、地下室（比墓穴更古老）、告解室、1740年 |
| 信任递进 | 0:问候 → 1:教堂历史 → 2:十字架影子变化 → 3:地下室门后有更古老的东西 → 4:首次下跪 → 5:揭示教会与屏障的关系 |
| 轮回记忆 | "你上次来教堂的时候，蜡烛灭了三根。" "椅子记得你。" |
| 死亡回响 | 蜡烛数量变化，钟声用你的名字替代次数 |
| SAN 退化 | "手在发抖" → "蜡烛亮了三根不正常" → "十字架转角度" → "你已被标记——不是被神，是被这个地方" |
| 禁用 | 世俗俚语、科学术语、非圣经隐喻 |

### 汤米·陈（Tommy Chen）

| 维度 | 规则 |
|------|------|
| 句式 | 摄影师观察体。用镜头/底片/显影术语比喻感知。"你对摄影感兴趣吗？" |
| 语气 | 年轻、好奇、逐渐被恐惧侵蚀。从爱好者到见证者 |
| 高频意象 | 相机、螺旋符号、底片、显影液、烟雾、胶片上的额外影子 |
| 信任递进 | 0:擦相机抬头 → 1:拍到一些东西 → 2:码头波纹圆形 → 3:地下室照片上的影子 → 4:螺旋符号 → 5:揭示相机记录能力 |
| 轮回记忆 | "我的相机存了太多你的照片。每次都不一样。每次都是你。" |
| 死亡回响 | "这张——我什么时候拍的？"（指着你的死亡照片） |
| SAN 退化 | "你确定那是你拍的吗？" → 屏幕上重叠的多个你 → "你的故事已经写了太多遍" |
| 禁用 | 长篇独白、宗教词汇、军事术语 |

### 埃德加·洛夫克拉夫特（Edgar Lovecraft）

| 维度 | 规则 |
|------|------|
| 句式 | 元叙事体。把玩家的经历当故事素材。"我正在写一个故事。关于一个不断回来的人。" |
| 语气 | 作家观察者。meta-aware 但不过度打破第四面墙。冷幽默 |
| 高频意象 | 笔记本、墨水、故事/叙事、空白页、笔迹、读者、结局、真实 vs 虚构边界 |
| 信任递进 | 0:角落写东西 → 1:需要读者 → 2:最好的恐怖是观察出来的 → 3:沃切斯特不需要虚构 → 4:故事会自己变化 → 5:揭示玩家即素材 |
| 轮回记忆 | "你的故事已经写了太多遍。每一次的结局都不一样。这本身就是最好的故事。" |
| 死亡回响 | "上次的故事……你没有读完。结局是——"停住。最后一页空白。不，有一滴血。 |
| SAN 退化 | "你的故事越来越有意思" → "你不是在调查沃切斯特。沃切斯特在调查你。" → "你说话的时候有些词会自己改变" |
| 禁用 | 直接叫玩家名字、游戏术语（AP/SAN/loop）、温情表达 |

## 写作 checklist

新增任意 NPC 台词前确认：
- [ ] 语气符合该 NPC 的句式偏好（不是"通用恐怖句式"）
- [ ] 高频意象来自该 NPC 的专属符号库
- [ ] 信任层级正确（低信任不泄露高信任信息）
- [ ] SAN 退化层级递增（不是突然跳到底层）
- [ ] 轮回记忆台词仅在 loop_min 满足时出现
- [ ] 无禁用表达
